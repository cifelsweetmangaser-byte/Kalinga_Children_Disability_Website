KALINGA — CHILDREN & INCLUSION ADVOCACY WEBSITE
================================================

PAGES
1. index.html   — Home page and advocacy introduction
2. privacy.html — Privacy Statement
3. contact.html — Contact form with NAME, EMAIL, and MESSAGE

OTHER FILES
- style.css  — Brown and white theme, responsive layout, fonts, icons, spacing
- script.js  — Mobile navigation and demo form confirmation

HOW TO OPEN
1. Download and extract the ZIP file.
2. Open the folder.
3. Open index.html in a web browser.
4. Use the menu to visit Privacy Statement and Contact Us.

DESIGN
- Main colors: brown and white, with warm beige accents.
- Fonts: Nunito headings and DM Sans body text.
- Icons: Font Awesome.
- Photos: external Unsplash images.
- Mobile-responsive layout.

IMPORTANT
This is a front-end educational project. The form does not send or save submitted details. The website does not intentionally use tracking cookies or analytics. External photographs, fonts, and icons need an internet connection.
